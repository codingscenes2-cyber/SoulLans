# Animation library

This directory holds Godot AnimationLibrary resources, AnimationTree resources and animation state-machine assets.

Initial target:
- Player locomotion blend space.
- Dodge and evasive movement.
- Weapon-specific attack sequences.
- Block, parry, riposte and hit reactions.
- Enemy locomotion, telegraphs, attacks and death.
- Boss phase transitions and signature moves.

Use a consistent humanoid skeleton wherever possible. Record source rig, retargeting changes and animation licence in the asset credits register. Keep combat timing synchronized with gameplay hit windows. No placeholder capsule animation should be treated as final.
